Case Study · Semester Project

Person Identification System

A face recognition system built on a convolutional neural network, where the interesting problem turned out to be enrollment rather than matching.

— recognition is easy; knowing who you know is not
Role Model training & implementation
Context Semester Project
Timeline Feb 2024 – Apr 2024
Focus CNNs, computer vision & ML

The problem

Identity verification done by hand does not scale. A person checking faces against a list is slow, gets slower as the list grows, and becomes less reliable the longer they do it. The task is repetitive in exactly the way humans are worst at and machines are best at.

But naive automation trades one problem for another. Matching raw pixels fails the moment lighting, angle, or expression changes — and those change constantly in any real setting. The system needs to recognise a person, not a photograph of them, which means learning features that survive the conditions rather than memorising images.

The real brief

Not "compare two images" — learn what makes a face that particular person's, and hold onto it between sessions.

Approach

I split the work into the two things it actually is: a vision problem (finding and normalising a face in a frame) and a learning problem (deciding whose face it is). Keeping them separate meant each could be debugged without the other confusing the picture.

  • Detection and preprocessing with OpenCV — locating the face in a frame and normalising it before anything is learned from it, so the model sees consistent input.
  • A CNN for recognition — chosen because convolutional layers learn spatial features directly from image data, rather than relying on hand-picked measurements.
  • Cloud-backed enrollment — enrolled identities persist in cloud storage, so the system knows who it knows across restarts instead of relearning each session.
  • Live camera inference — running identification against a live feed rather than still images, which is where the practical failure modes actually appear.

Decisions worth explaining

A CNN over classical feature matching

Recognition is handled by a trained convolutional network rather than hand-engineered facial measurements.

Trade-off: needs training data and compute, and the result is far harder to inspect when it gets something wrong. Classical features were simply too brittle across lighting and angle to be worth it.

Separating detection from recognition

OpenCV finds and normalises the face; the CNN only ever decides whose it is.

Trade-off: two stages to maintain, and detection failures silently become recognition failures. Worth it — a single end-to-end model would have been much harder to debug at this scale.

Cloud storage for enrolled identities

Enrollment data lives in cloud storage rather than in a local file beside the script.

Trade-off: introduces a network dependency into what could have been an offline tool. It made enrolled identities durable and the system genuinely usable across sessions and machines.

Testing against a live feed, not a dataset

Evaluation ran on a live camera rather than only held-out test images.

Trade-off: harder to quantify than a clean accuracy number on a fixed dataset. It surfaced the problems that only appear in motion — angle, backlighting, partial occlusion.

What I built

  • A trained CNN model for face recognition, built with standard ML frameworks.
  • An OpenCV detection and preprocessing stage that locates and normalises faces before recognition.
  • Cloud-backed enrollment storage, so registered identities persist between sessions.
  • A live identification loop that recognises enrolled people from a camera feed in real time.

Outcome

The finished system identifies enrolled people from a live camera feed, with their identities persisted in cloud storage between runs. Built over a single semester as an AI and machine learning project, it was my first proper encounter with the gap between a model that scores well on test data and one that holds up pointed at a real room — a distinction that has informed everything I have built since.
